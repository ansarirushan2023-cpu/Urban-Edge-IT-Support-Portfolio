# Urban Edge SA — IT Support & Digital Operations Hub

**Independent portfolio concept by Rushan Ansari**  
**Target area:** IT Support / IT Administration

> **Important:** This repository is an independently created demonstration using 100% fictional/mock data. It is **not** an audit of Urban Edge SA, does not represent Urban Edge SA's actual IT environment, and contains no confidential or internal company information.

## Project overview

I created this project to demonstrate how I would approach day-to-day IT support and administration in a growing residential construction business.

The project focuses on practical operational areas rather than advanced infrastructure engineering:

- IT helpdesk and ticket management
- IT asset tracking
- user and system access administration
- employee onboarding and offboarding
- reusable knowledge-base documentation
- basic security health monitoring
- management reporting
- prioritised IT improvement planning

## What is included

| Component | Demonstrates |
| --- | --- |
| Helpdesk | Ticket lifecycle, impact/urgency prioritisation, SLA tracking, root cause and resolution documentation |
| Asset Register | Device ownership, warranty, patching, endpoint security and compliance tracking |

The main Excel workbook contains **30 fictional employees, 50 mock helpdesk tickets, 46 IT assets, 100 access records, 30 knowledge-base articles and 15 security controls**.

## Improvement approach

The project intentionally does **not** assume that a new IT Support Administrator should arrive and immediately replace existing systems.

The first-month approach used in the prototype is:

1. **Understand** the actual users, systems, support channels and recurring issues.
2. **Validate** assets, accounts, access and open support work.
3. **Deliver quick wins** based on evidence.
4. **Report and recommend** practical next steps to management.

## Suggested 5-minute review

For a short demonstration, I would review the project in this order:

1. **IT_Ticket_Register** — how a support problem moves from submission to priority, SLA, root cause and resolution.
2. **Asset_Register** — how company technology can be tracked by owner, status and basic endpoint controls.
3. **IT_Dashboard** — how the detailed operational data becomes useful management information.
4. **Improvement_Plan** — how findings are converted into practical and measurable actions.

## Power BI
